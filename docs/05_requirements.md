# Требования к продукту (User Stories)

## 1. Роли пользователей
- **Гость** — неавторизованный пользователь.
- **Пользователь** — авторизованный пользователь, владелец своих задач и категорий.

## 2. Пользовательские истории (User Stories)

### US-01: Регистрация
**Как** гость, **я хочу** зарегистрироваться в системе, **чтобы** иметь личное пространство для своих задач.
**Критерии приемки:**
- Форма регистрации содержит поля: Email, Пароль, Повтор пароля.
- Email должен быть уникальным.
- Пароль должен быть не менее 6 символов.
- После успешной регистрации пользователь автоматически авторизуется.

### US-02: Авторизация (Вход)
**Как** зарегистрированный пользователь, **я хочу** входить в систему, **чтобы** получать доступ к своим задачам.
**Критерии приемки:**
- Форма входа содержит Email и Пароль.
- При неверных данных выводится сообщение об ошибке.
- При успешном входе выдается JWT-токен и происходит переход на главную страницу.

### US-03: Создание задачи
**Как** пользователь, **я хочу** создавать новые задачи, **чтобы** фиксировать свои планы.
**Критерии приемки:**
- Форма создания содержит поля: Заголовок (обязательно), Описание (опционально), Дедлайн (опционально), Категория (опционально).
- Задача сохраняется и сразу отображается в общем списке.

### US-04: Просмотр списка задач
**Как** пользователь, **я хочу** видеть список всех своих задач, **чтобы** понимать текущий объем работы.
**Критерии приемки:**
- Отображаются только задачи текущего пользователя.
- В списке видны: заголовок, статус (выполнено/не выполнено), дедлайн, категория.

### US-05: Редактирование задачи
**Как** пользователь, **я хочу** редактировать задачи, **чтобы** вносить изменения в планы.
**Критерии приемки:**
- Можно изменить заголовок, описание, дедлайн, категорию.
- Изменения сохраняются и сразу отображаются в интерфейсе.

### US-06: Изменение статуса задачи
**Как** пользователь, **я хочу** отмечать задачу выполненной, **чтобы** видеть свой прогресс.
**Критерии приемки:**
- Можно переключить статус задачи (выполнено/не выполнено) в один клик.
- Выполненные задачи визуально отличаются (например, зачеркнутый текст).

### US-07: Удаление задачи
**Как** пользователь, **я хочу** удалять ненужные задачи, **чтобы** не засорять список.
**Критерии приемки:**
- Удаление происходит после подтверждения в модальном окне.
- Задача исчезает из списка.

### US-08: Управление категориями
**Как** пользователь, **я хочу** создавать и удалять категории, **чтобы** группировать задачи по сферам жизни (Работа, Учеба, Дом).
**Критерии приемки:**
- Можно создать категорию с уникальным именем.
- При удалении категории задачи не удаляются, а остаются без категории.

### US-09: Фильтрация и сортировка
**Как** пользователь, **я хочу** фильтровать задачи по категориям и статусу, **чтобы** быстро находить нужное.
**Критерии приемки:**
- Можно отфильтровать задачи по одной или нескольким категориям.
- Можно отфильтровать только выполненные или только невыполненные задачи.
- Можно отсортировать по дате дедлайна или по алфавиту.

### US-10: Защита данных
**Как** пользователь, **я хочу** быть уверенным, что другие не видят мои задачи, **чтобы** сохранять приватность.
**Критерии приемки:**
- Неавторизованный пользователь при попытке зайти на главную страницу перенаправляется на страницу входа.
- API не позволяет получить или изменить задачи, принадлежащие другому пользователю.
