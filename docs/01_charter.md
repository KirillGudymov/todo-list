# Устав проекта (Project Charter)

## 1. Название проекта
Веб-сервис для управления личными задачами (ToDo List).

## 2. Цель проекта
Разработать легковесное и удобное веб-приложение для планирования личных задач с возможностью категоризации, установки дедлайнов и отслеживания статуса выполнения. 

## 3. Границы проекта (Scope)
**Входит в проект:**
- Регистрация и авторизация пользователей (JWT).
- Создание, редактирование, удаление и просмотр задач.
- Создание категорий для группировки задач.
- Фильтрация задач по категориям и статусу.

**НЕ входит в проект (Out of Scope):**
- Мобильное приложение (iOS/Android).
- Push-уведомления и интеграция с email.
- Совместный доступ к задачам (командная работа).
- Интеграция с внешними календарями.

## 4. Ключевые вехи (Milestones)
- **Спринт 1 (Фундамент):** Настройка инфраструктуры, проектирование БД, UI-прототипы.
- **Спринт 2 (Разработка ядра):** Написание CRUD-операций, верстка интерфейса, интеграция.
- **Спринт 3 (Сдача):** Тестирование, контейнеризация (Docker), написание отчета, защита.

## 5. Ограничения и предположения
- **Ограничения:** Учебный проект, срок — 3 недели, бюджет — 0 руб. Команда из 4 человек, совмещающих учебу и разработку.
- **Предположения:** У всех участников установлен Git, Node.js, Python и Docker.

## 6. Команда проекта
- **У1:** Тимлид, Backend-разработчик (Auth), CI.
- **У2:** Backend-разработчик (База данных, CRUD), аналитика сроков.
- **У3:** Frontend-разработчик (Основной UI), тестирование.
- **У4:** DevOps (Docker), Frontend (Auth UI), анализ стейкхолдеров.
